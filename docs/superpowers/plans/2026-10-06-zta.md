# ZTA Demo Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. No per-task delegation.

**Goal:** 建立使用者指定的 SP 800-207 可執行展示。
**Architecture:** Envoy 執行 mTLS 與逐請求 ext_authz；PE 決策，PA 管理 session 並重評估。SQLite-backed Context 提供政策、裝置與 telemetry；Identity 驗證 WebAuthn。
**Tech Stack:** Python 3.12, FastAPI, httpx, py_webauthn, cryptography, Envoy, Docker Compose.
**Spec:** ../../design.md

## Global Constraints
- 不編輯 sources/；全部輸出於 zta-demo/。
- PE/PA 分開服務；Resource 無 host port；不用 service mesh。
- 真正 WebAuthn 與 device mTLS，不設 password 或 authentication bypass。
- Docker 未安裝則如實記錄，不自動安裝系統服務。

## Review Focus
- challenge replay / wrong origin / absent user verification 必須拒絕。
- forged certificate/header 與 session/device mismatch 必須拒絕。
- PE、context、identity 不可用時 fail closed。
- policy change、human expiry 與 revoke 必須影響 active session。
- Stream 遇 revoke / PA unavailable 必須終止。
